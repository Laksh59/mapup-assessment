# 🚀 MapUp Full Stack Assessment

## 📌 Overview
This project implements a geofence-based vehicle tracking system that detects ENTRY and EXIT events based on vehicle location updates.

---

## 🧠 Features
- Detects if a vehicle is inside or outside a geofence
- Generates ENTRY and EXIT events
- Handles multiple geofences
- REST API for processing location data
- Frontend UI for visualization (if applicable)

---

## 🛠️ Tech Stack
- Backend: Go (Golang)
- Frontend: React (JavaScript)
- Containerization: Docker
